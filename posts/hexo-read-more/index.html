为 Hexo 设置阅读全文功能

本文发布于 2022 年，部分内容可能已过时，请注意甄别。

前言

为 Hexo 文章设置一个链接 “阅读全文” 来进入文章的详情页，同时只显示前言部分——就是你现在看到的样子。
点击阅读全文看看是如何实现的

使用 手动截断

在需要截断的位置添加 <!--more--> ，之后的内容只有在点击文章详情页才能看到，并且 <!--more--> 之前的内容在文章详情里也能一并看到

利用文章的 front-matter

在文章的 front-matter 添加 description ，并添加描述，此描述只在首页显示，在文章详情页不会显示

自动形成摘要

修改主题配置文件：添加如下配置，默认截取150字符，可以根据需要自行设定

auto_excerpt:
  enable: true
  length: 150

建议使用 <!--more--> ，可以精确控制需要显示的摘要内容，也可以让 Hexo 中的插件更好地识别。
